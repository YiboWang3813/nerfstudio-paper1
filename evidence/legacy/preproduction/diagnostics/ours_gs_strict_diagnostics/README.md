# Ours GS-Strict Diagnostics

This output bundle stores diagnostics for the Ours GS-strict endpoint.

- A1 per-run table: `outputs/ours_gs_strict_diagnostics/tables/a1_corridor_sweep_per_run.tsv`
- A1 summary table: `outputs/ours_gs_strict_diagnostics/tables/a1_corridor_sweep_summary.tsv`
- A1 analysis: `outputs/ours_gs_strict_diagnostics/notes/a1_analysis.md`
- Checkpoints are externalized through `system.checkpoint_root`.
